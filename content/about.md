This is my personal archive of study notes from the IT courses and certifications I've taken over the years — CompTIA A+, Microsoft Azure Fundamentals (AZ-900), networking, Linux, security and more.

Instead of keeping scattered documents in the cloud, everything lives here as plain Markdown files in a Git repository, so the notes are searchable, versioned and easy to update.

## How it works

- Every note is a Markdown file in the `content/` folder. Folders become categories.
- Images, GIFs and videos live next to the notes that use them.
- On every push to GitHub, a GitHub Action rebuilds the notes index and deploys the site to GitHub Pages.

Source code: [github.com/StoyanKYM](https://github.com/StoyanKYM)
