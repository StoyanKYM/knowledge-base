> 🎯 Добрата документация и reporting са **по-важни от самото хакване**. Taking notes is a must!

| Инструмент | Предназначение |
|---|---|
| **GitLab** | Лични проекти / документация |
| **GitHub** | Лични проекти и open source |
| **Obsidian** | Записки (vault в клонирания проект) |

**Добавяне на SSH key в GitLab:** Preferences → SSH Keys → Add new key → клонирай проекта → добави Obsidian vault в проекта.

💡 Задължителни plugins/setup за Obsidian:
- **Git** → Pull on startup
- **Image Toolkit**
- Отделна папка за снимките
- **Omnisearch** (когато записките станат много)
- Editor → show line numbers, readable line length
- **Folder Notes**

- **Mail Relay** — атака, която изпраща имейл от чуждо име/имейл.
