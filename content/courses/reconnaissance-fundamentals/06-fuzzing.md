---
title: 6. 🧪 Fuzzing за конкретни уязвимости
updated: 2026-10-18
---

| Уязвимост | Как се fuzz-ва |
|---|---|
| **SQL Injection** | При поле за търсене: единична кавичка `'` и по-дълъг string + `'` |
| **XSS / HTML Injection** | Вкарваме наш код, който приложението изпълнява в поле за търсене |
| **OS Command Injection** | Изпълнява системна команда; fuzz-ва се лесно с `whoami`, `|`, `&&`, `;` |
| **Directory Traversal** | Достъп до файлове |
| **Access Control** | Достъп до нещо, до което не трябва да имаме |
| **File Upload** | Качване на файлове |
