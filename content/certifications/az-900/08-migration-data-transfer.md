## 8.1 🧳 Azure Migrate (миграция към Azure)
- **Hub (централизирано място)** за оценка и миграция на On-premises Datacenter (сървъри, бази данни, уеб приложения) към Azure.
- **Unified Migration Platform (единна платформа)** — един портал за стартиране, изпълнение и проследяване.
- Интегрира се с други услуги и с ISV (независими доставчици на софтуер).
- 🎯 **Не е предназначен** за прехвърляне на големи обеми данни (за това — Data Box).

| Инструмент | Предназначение |
|---|---|
| Azure Migrate: Discovery and Assessment (откриване и оценка) | Откриване и оценка на сървъри (VMware, Hyper-V, физически) |
| Azure Migrate: Server Migration (миграция на сървъри) | Миграция на VMware/Hyper-V VMs, физически сървъри и VMs от други облаци |
| Data Migration Assistant (асистент за миграция на данни) | Самостоятелен инструмент за оценка на SQL Server — блокиращи проблеми, неподдържани функции, оптимален път |
| Azure Database Migration Service (услуга за миграция на бази данни) | Миграция към SQL Server на VM, Azure SQL Database или SQL Managed Instance |
| Azure App Service Migration Assistant | Оценка и миграция на .NET и PHP уеб приложения към App Service |
| Azure Data Box | Преместване на големи офлайн обеми данни |

## 8.2 📦 Azure Data Box
- **Physical Migration Service (физическа услуга за миграция)** — Microsoft изпраща защитено устройство (до **80 TB** използваем капацитет) в здрав корпус чрез регионален куриер.
- Поръчва се от Azure Portal за **Import (импорт) или Export (експорт)**; свързва се към мрежата и се настройва чрез локален Web UI.
- След връщане данните се качват автоматично; процесът се проследява от край до край в портала.
- Подходящ при **ограничена или липсваща мрежова свързаност** и големи обеми.

## 8.3 🗂️ Инструменти за файлове и малки групи файлове

| Инструмент | Тип | Описание |
|---|---|---|
| **AzCopy** | Command-line Utility (команден ред) | Копиране на Blobs или файлове към/от Storage Account; Upload, Download, копиране между акаунти, Synchronization (синхронизация); работи и с други облачни доставчици |
| **Azure Storage Explorer** | Graphical Tool (графичен инструмент) | Самостоятелно приложение за Windows, macOS и Linux; **използва AzCopy отдолу**; Upload, Download, преместване между акаунти |
| **Azure File Sync** | Хибридна синхронизация | Централизира File Shares в Azure Files, като запазва локален Windows File Server с кеш на често използваните файлове; **двупосочна (Bi-directional)** автоматична синхронизация — „мини CDN“ |

🎯 Сценарий: централизиране на файлове от клонове + бърз локален достъп → **Azure File Sync**.
