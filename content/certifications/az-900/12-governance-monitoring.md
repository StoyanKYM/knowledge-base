## 12.1 ⚙️ Azure Resource Manager – ARM (мениджър на ресурси)
- **Услугата за внедряване и управление** на Azure — управленски слой за създаване, актуализиране и изтриване на ресурси.
- 🎯 **Всяко действие с Azure ресурси минава през ARM** (портал, CLI, PowerShell, API).

## 12.2 📝 Infrastructure as Code – IaC (инфраструктура като код)
- Управление на инфраструктурата чрез редове код. На въвеждащо ниво: Azure Cloud Shell, Azure PowerShell, Azure CLI. На напреднало: цели внедрявания чрез повторяеми шаблони.
- Предимства: Consistency (последователност), по-малко грешки, **Version Control (контрол на версиите)**, тестване, идентични внедрявания в много региони.

| | ARM Templates (ARM шаблони) | Bicep Files (Bicep файлове) |
|---|---|---|
| Синтаксис | **Declarative JSON (декларативен JSON)** | Собствен **декларативен** език, по-прост и кратък |
| Внедряване | ARM | Bicep се компилира и ARM внедрява средата |
| Общи характеристики | Кодът се **валидира преди изпълнение**; ресурсите се създават **паралелно** (50 инстанции наведнъж); дефинира се само желаното състояние; могат да изпълняват PowerShell/Bash скриптове преди или след създаване | |

🎯 Сценарий: еднакви 15 VMs в няколко региона, с контрол на версиите и по-малко грешки → **ARM Templates / Bicep**.

## 12.3 🧰 Инструменти за управление
- **Azure Portal (портал)** — уеб графичен интерфейс.
- **Azure Cloud Shell** — браузърна обвивка с Azure CLI и PowerShell.
- **Azure CLI** и **Azure PowerShell** — команден ред и скриптове.
- **Azure Arc** — разширява управлението на Azure към хибридни и мулти-облачни среди (вижте [1.3](01-cloud-concepts.md)).

## 12.4 💡 Azure Advisor (съветник)
- Персонализирани препоръки в 5 категории: **Cost (разходи), Security (сигурност), Reliability (надеждност), Performance (производителност), Operational Excellence (оперативно съвършенство)**.
- Препоръките могат да се изпълнят веднага, да се отложат или отхвърлят.
- 🎯 **Не сравнява** On-premises с Azure разходи (за това → TCO Calculator).
- 🎯 Работи на ниво **един Subscription** — няма консолидиран изглед за много абонаменти; трябва да се превключва между тях.

## 12.5 📈 Azure Monitor (наблюдение)
- Цялостна платформа за **събиране, анализиране, визуализиране и реагиране** на Telemetry (телеметрия — автоматично събирани и предавани данни) от Azure, On-premises и мулти-облачни ресурси.
- Събира метрики и логове (напр. CPU %) — данните могат да задействат **Autoscaling**.

| Компонент | Предназначение |
|---|---|
| **Log Analytics** (анализ на логове) | Писане и изпълнение на заявки към събраните логове |
| **Azure Monitor Alerts** (известия) | Автоматично известяване при преминаване на праг; по **метрики** (почти в реално време, напр. CPU > 80%) или по **логове** |
| **Application Insights** | **Application Performance Management – APM** (управление на производителността на приложения) за уеб приложения в Azure, On-premises или друг облак: Anomaly Detection (откриване на аномалии), Dependency Tracking (проследяване на зависимости), метрики, потребителски анализи. 🎯 Bottlenecks (тесни места) и бавни зависимости → **Application Insights** |

## 12.6 🩺 Наблюдение на състоянието на услугите

| Услуга | Обхват |
|---|---|
| **Azure Status** (статус на Azure) | **Глобален** изглед на всички Azure услуги и региони |
| **Azure Service Health** (здраве на услугите) | Персонализиран изглед на **услугите и регионите, които вие използвате** — прекъсвания, планирана поддръжка, Health Advisories (съвети); може да изпраща известия |
| **Azure Resource Health** (здраве на ресурсите) | Здравето на **конкретните ваши ресурси** |

## 12.7 🏷️ Tags (етикети)
- Метаданни (Key-Value двойки) към ресурси за организиране, отчитане на разходи и автоматизация; могат да се налагат чрез Azure Policy.

## 12.8 🛒 Azure Marketplace
- Каталог с решения от Microsoft и трети страни, които могат да се внедрят в Azure.
- **Azure Solution (решение)** — комбинация от базови услуги, използвани като едно цяло.

## 12.9 📋 Обобщение: инструменти за управление

| Въпрос | Услуга |
|---|---|
| Кой може да прави нещо? | RBAC |
| Какво е позволено в средата? | Azure Policy |
| Как да предотвратя случайно изтриване? | Resource Locks |
| Как да организирам много абонаменти? | Management Groups |
| Как да управлявам хибридни/мулти-облачни ресурси? | Azure Arc |
| Как да внедрявам еднакво и повторяемо? | ARM Templates / Bicep |

| Unified / Enterprise (обединен / корпоративен) | Големи организации; **Premier вече не съществува** (заменен от Unified) |
