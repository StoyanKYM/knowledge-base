## 10.1 📖 Основни понятия

| Понятие | Значение |
|---|---|
| **Threat (заплаха)** | Човек или събитие, което може да навреди на ценен ресурс |
| **Vulnerability (уязвимост)** | Слабост в дизайна, бъг в кода или липса на защитни мерки |
| **Threat Actor (злонамерен субект)** | Човек/организация, които умишлено причиняват вреда |
| **Risk (риск)** | Вероятност и въздействие от експлоатацията на уязвимост |
| **Exploit (експлойт)** | Код, който се възползва от уязвимост |
| **Information Security** | Защита на **самите данни** |
| **Information System Security** | Защита на **устройствата**, които пазят данните |
| **Internal / External Threats** | Хора в организацията / хакери, събития, околна среда |
| **CVE – Common Vulnerabilities and Exposures** | Публичен списък с известни уязвимости (повечето имат експлойт) |

## 10.2 🔺 CIA Triad (триадата CIA)

| Принцип | Въпрос | Средства |
|---|---|---|
| **Confidentiality (поверителност)** | Колко защитена е информацията? | **Encryption (криптиране)** |
| **Integrity (цялостност)** | Променени ли са данните при пренос/съхранение? | **Hashing (SHA)**, **Checksum** |
| **Availability (наличност)** | Достъпни ли са данните винаги? | Uptime, **Redundancy (резервираност)** |

## 10.3 🕳️ Видове уязвими системи
- **Non-compliant Systems** — не отговарят на одобрената базова конфигурация.
- **Unpatched Systems** — без кръпки.
- **Unprotected Systems** — без антивирус/Firewall.
- **EOL – End of Life OS** — производителят спира кръпките.
- **BYOD** — лични устройства → MDM/MAM.

## 10.4 💥 Атаки

| Атака | Описание | Защита / бележки |
|---|---|---|
| **Zero-day (атака от нулевия ден)** | Уязвимост, експлоатирана **преди производителят да знае** и да издаде кръпка | Signature-based защитата **не я открива** |
| **DoS – Denial of Service** | Претоварва ресурсите от една машина | — |
| **DDoS – Distributed DoS** | Много машини (Botnet) едновременно | **Blackhole/Sinkhole** (към несъществуващ сървър), **IPS**, **Cloudflare** |
| **DNS Amplification** | Малки DNS заявки → огромни отговори към жертвата | — |
| **IP Spoofing** | Подправен **IP адрес на източника** — **Layer 3** | 🎯 Пример за IP spoofing → **On-path attack** |
| **MAC Spoofing** | Подправен MAC адрес (`sudo ifconfig en0 ether <MAC>`) — заобикаля **MAC Filtering** | — |
| **ARP Spoofing / Poisoning** | Фалшиви ARP съобщения в LAN — **Layer 2**; предшественик на други атаки | ❌ Това е MAC spoofing, не IP spoofing |
| **On-path Attack** (бивш **MITM – Man-in-the-Middle**) | Атакуващият застава между два хоста | **Replay** — повтаря уловени данни; **Relay** — препредава |
| **SQL Injection** | SQL заявка през входни данни на уеб приложение | 🎯 **Input Validation (валидиране на входа)** |
| **Injection Attack** | SQL / HTML / XML / LDAP | — |
| **XSS – Cross-Site Scripting** | Злонамерен **JavaScript** в доверен сайт; жертвата е **потребителят** | Типове: **Stored/Persistent**, **Reflected**, **DOM-based** |
| **XSRF / CSRF – Cross-Site Request Forgery** | Браузърът на логнатата жертва изпраща **нежелана заявка** | ❌ Не краде данни директно, не изпълнява JS |
| **Insider Threat (вътрешна заплаха)** | Служител злоупотребява с легитимния си достъп | — |
| **Supply Chain Attack (атака по веригата за доставки)** | Атакува по-слаб доверен партньор | Вижте по-долу |
| **Evil Twin (зъл близнак)** | Фалшива Wi-Fi точка, изглеждаща легитимна — подслушва | — |
| **Evil Base Station / IMSI Catcher (Stingray)** | Фалшива мобилна кула — прихваща **IMSI**, локация, разговори | — |

🎯 **XSS vs CSRF:** *„публични постове + изскачащ прозорец за парола + компрометирани акаунти“* → **XSS** (краде данни чрез скрипт). CSRF **извършва действия от твое име** чрез подвеждащ линк (напр. банков превод).

## 10.5 🔗 Supply Chain Attacks
| Вид | Описание |
|---|---|
| **Software Supply Chain** | Зловреден код в легитимен софтуер/ъпдейт (🎯 **SolarWinds**) |
| **Hardware Supply Chain** | Модифициран чип/платка/рутер при производство или транспорт (**Semiconductors – полупроводници**) |
| **Service Provider / Third-Party** | Крадат акаунтите на външен доставчик (ИТ поддръжка, климатична фирма) |

## 10.6 🔓 Password Cracking (разбиване на пароли)
- **Password Analysis Tool** — тества силата на паролите; **Password Cracker** — отгатва систематично.

| Метод | Описание |
|---|---|
| **Password Guessing** | Слаба парола, познатa от човек |
| **Dictionary Attack (речникова атака)** | Списък с възможни пароли |
| **Brute-force Attack (груба сила)** | Всяка възможна комбинация |
| **Cryptanalysis Attack** | Сравнява с предварително изчислени хешове — **Rainbow Tables** |
