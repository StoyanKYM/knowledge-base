**Shell Script (скрипт на обвивката)** — текстов файл с команди, интерпретирани от компютъра.

| Разширение | Език | Платформа | Описание |
|---|---|---|---|
| **.bat** | Batch | 🖥️ Windows | Класически; команди за `cmd.exe` |
| **.ps1** | **PowerShell** | 🖥️ Windows | Модерен, мощен, обектно ориентиран — по-сложни скриптове от .bat |
| **.vbs** | VBScript | 🖥️ Windows | Стар (Visual Basic Scripting Edition), заменен от PowerShell |
| **.sh** | Shell (Bash) | 🐧 Linux / macOS | Основният формат |
| **.js** | JavaScript | 🌐 Всички | Уеб; Node.js за сървъри и автоматизация |
| **.py** | Python | 🌐 Всички | Любимецът на системните администратори |

- **`echo`** — отпечатване на екрана; **Variables (променливи)** — съхраняват стойности.

## ⚙️ Употреби на автоматизацията
- ⚙️ **Basic Automations** — почистване на Temp папки, отчети по имейл.
- ⚙️ **Machine Restart** — рестартиране на стотици машини / в извънработно време.
- ⚙️ **Network Drive Remapping** — автоматично мапване на новия файлов сървър при логване.
- 📦 **Application Installation** — масово тихо инсталиране (напр. .msi чрез PowerShell).
- 📦 **Update and Security Patch Installation** — автоматични кръпки.
- 📂 **Backup Automation** — планиран Backup с проверка за успех.
- 📂 **Information Gathering** — одит на хардуер и лицензи.

⚠️ Рискове (от конспекта): неволно въвеждане на зловреден код, промяна на системни настройки, срив от неправилно управление на ресурсите — тествайте скриптовете в Sandbox.
