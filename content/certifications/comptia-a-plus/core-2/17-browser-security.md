## 17.1 📥 Безопасно инсталиране
- Само от **Trusted Sources (доверени източници)**.
- 🎯 **Hash Verification (проверка на хеша)** — **Hash = Digital Fingerprint (цифров отпечатък)**: фиксиран низ; промяна на един символ дава напълно различен хеш (**Avalanche Effect – ефект на лавината**). Ползи: **Integrity**, откриване на подменени файлове, пароли се пазят като хешове.

| Платформа | Команда |
|---|---|
| Windows (CMD) | `certutil -hashfile файл.exe sha256` |
| Windows (PowerShell) | `Get-FileHash C:\файл.exe` (SHA-256 по подразбиране); `-Algorithm MD5` |
| macOS / Linux | `shasum -a 256 файл`; `md5` (macOS) / `md5sum` (Linux) |

⚠️ **Hash Mismatch (несъответствие)** → файлът е повреден или с вграден малуер → **изтеглете отново от сигурен източник / свържете се с разработчика**.

## 17.2 🧩 Разширения и настройки
- **Extensions (разширения)** — нови функции (Ad-blocker, Password Manager).
- **Plug-ins (плъгини)** — по-стара технология (Flash, Java), премахната от съображения за сигурност.
- **Apps**, **Search Providers (доставчици на търсене)**, **Themes (теми)**.
- **Password Managers** — една главна парола; спират **Password Reuse (повторната употреба)**.
- **Pop-up Blockers & Ad-blockers**.
- **Profile Synchronization** — синхронизира предпочитания, пароли, отметки.

## 17.3 🔒 Сертификати
- **Certificate (сертификат)** — цифровата „лична карта“; изгражда криптирана връзка чрез **PKI – Public Key Infrastructure** (публичен + частен ключ).
- **SSL/TLS Web Certificates** — катинарчето; HTTPS; издават се от **CA – Certificate Authority** (DigiCert, Let’s Encrypt); браузърите имат **Trusted Root CA List**.
- 🎯 *„Your connection is not private“* — проверете:
  1. **Expired Certificate (изтекъл)**;
  2. 🎯 **Incorrect Date/Time (грешна дата/час)** — най-честата уловка (изтощена CMOS батерия);
  3. **Invalid / Self-Signed (самоподписан)** — не е от официално CA.
- 💡 Тест: **badssl.com**.

## 17.4 🍪 Cache, Cookies, Sessions

| | Cache (кеш) | Cookies (бисквитки) | Sessions (сесии) |
|---|---|---|---|
| Къде | На компютъра | На компютъра (в браузъра) | **На уеб сървъра** |
| Съдържание | Картинки, HTML, CSS, JS | Малки текстови низове (ID, език, количка) | Критични данни, статус на логване |
| Цел | **Скорост** | „Помнене“ и проследяване | **Сигурност** |
| Изтичане | При изчистване | Месеци/години (Persistent) | Бързо (затваряне / 15–30 мин) |
| Риск | Нисък | Среден — **Session Hijacking** (чрез XSS) | Висок, но без директен достъп |

- **Сесия + бисквитка:** сървърът създава Session → генерира **Session ID** → записва го в Cookie → браузърът го показва при всеки клик („номерче за гардероб“) → Log out унищожава сесията.
- **First-party Cookies** — от посетения сайт (функционалност); **Third-party Cookies** — от рекламодатели (проследяване).
- 🎯 Сайтът се показва счупен → **Clear Browser Cache**.

**Видове кеш:**
| Кеш | Описание |
|---|---|
| Browser Cache | Уеб елементи |
| Desktop / OS / App Cache | Икони, thumbnails (`IconCache.db`), Temp (`AppData\Local\Temp`) |
| **CPU Cache (L1, L2, L3)** | Хардуерна памет в процесора; L3 се споделя между ядрата |
| **DNS Cache** | Имена → IP; изчиства се с `ipconfig /flushdns` |

## 17.5 🕶️ Private / Incognito Browsing
- Не се пазят бисквитки, история, кеш, пароли след затваряне.
- ⚠️ **НЕ прави анонимен** — ISP и системният администратор виждат къде влизаш. Анонимност дават VPN/Proxy.

## 17.6 🔐 Secure DNS и проксита
- Обикновеният DNS (**UDP 53**) е в **Plain Text** → **DNS Spoofing / Poisoning** (фалшив IP в кеша).

| Secure DNS | Порт | Особеност |
|---|---|---|
| **DoH – DNS over HTTPS** | **443** | Скрит в уеб трафика — неразличим, заобикаля цензура |
| **DoT – DNS over TLS** | **853** | Отделен протокол — лесно се наблюдава/блокира от администратора |

| Proxy | Описание |
|---|---|
| **Forward Proxy** | Пред **клиентите**: **Content Filtering**, **Caching** (спестява трафик), анонимност |
| **Reverse Proxy** | Пред **уеб сървърите** (в DMZ): **Load Balancing**, WAF, **SSL Termination** |
| **Transparent Proxy** | Без знание и настройка от клиента — училища, хотели |
| **Anonymous Proxy** | Скрива оригиналния IP |

🎯 **Proxy vs VPN:** Proxy работи на ниво **приложение** (обикновено само браузъра) и обикновено **не криптира**; **VPN** работи на ниво **ОС** и криптира **целия** трафик.
