👉 Linux = сървъри; Windows = корпоративни работни станции. Изпитът е силно фокусиран върху Windows, но има 2–3 въпроса за Linux.
👉 **В Linux всичко е файл** — и директориите.

## 7.1 🧩 Компоненти на ОС
- **Shell (обвивка)** — средата, чрез която общуваш със системата: **GUI (графична)** или **Terminal (текстова)**. Видове: **Bash – Bourne-Again Shell**, **zsh**, **ksh**. `echo $SHELL` — текущият; `chsh` — смяна. Терминал: **Ctrl + Alt + T**.
- **Bootloader (зареждаща програма)** — първата програма; зарежда ядрото в паметта. **GRUB (Grand Unified Bootloader)** и **LILO (Linux Loader)**. „Мост“ между хардуерната инициализация и ОС.
- **Kernel (ядро)** — модулно и с отворен код; Process, Memory, Device Management; работи в Kernel Space.
- **systemd (System Daemon)** — **първият процес** (PID 1); стартира всички услуги **паралелно (Parallelization)**. Управление: `systemctl start sshd`, `systemctl status bluetooth`.
- **TTY (Teletype Typewriter)** — входно-изходен терминал; командата `tty` показва текущия.

## 7.2 👹 Daemons (демони)
- **Daemon** = Linux еквивалентът на **Windows Service**. Имената обикновено завършват на **„d“** (`httpd`, `sshd`, `systemd`).
- 👉 Не всеки процес е демон, но всеки демон е процес. Демонът стартира при boot, работи до изключване и не е свързан с потребителската сесия („сирак“ — orphan).
- 💡 Аналогия: процесът е приятел на гости; демонът е хладилникът, който работи денонощно.
- Всеки процес има **PID – Process ID**.

## 7.3 📄 Важни конфигурационни файлове

| Файл | Предназначение |
|---|---|
| **`/etc/passwd`** | Информация за потребителските акаунти |
| **`/etc/shadow`** | **Криптираните (хеширани) пароли** — по един запис за всеки потребител от /etc/passwd |
| **`/etc/hosts`** | Локално съпоставяне IP ↔ име (преди DNS) |
| **`/etc/fstab`** | Как се **монтират** дисковете и дяловете |
| **`/etc/resolv.conf`** | Настройки на **DNS клиента** |

## 7.4 🧭 Навигация, файлове и права
- `ls -l` — дълъг формат; `ls -la` — + скритите файлове. Първата буква **d** = директория; правата са за **user – group – others**.
- Цветове: бели — файлове; тъмносини — директории; светлосини — връзки; зелени (маркер **t**) — **Sticky** директория.
- `cp` / `mv source destination` — копиране / преместване (= копиране + изтриване).
- `cat` — показва съдържанието; текстови редактори: **nano**, **pico** (лесни, визуални), **vi** (модален), **vim** (подобрен vi).

### 🔐 chmod vs chown
| Команда | Какво променя | Пример |
|---|---|---|
| **`chmod` (Change Mode)** | **Правата** — **r** (Read=4), **w** (Write=2), **x** (Execute=1) | `chmod 755 file` → собственик rwx (7), група r-x (5), други r-x (5); `chmod +x script.sh`; `chmod 777` — всички всичко |
| **`chown` (Change Owner)** | **Собственика** (и групата) | `chown ivan:accounting report.txt` |
| `chgrp` | Само групата | — |

💡 Аналогия: chown казва кой държи нотариалния акт на къщата; chmod — кой може да влиза, да боядисва или само да гледа.

## 7.5 🔍 Търсене, дискове и файлови системи

| Команда | Предназначение |
|---|---|
| **`find /dir -name file`** | Търси **файлове** по име/тип/права |
| **`grep -i term file`** | Търси **текст във файл** (Global Regular Expression Print) |
| **`df`** (Disk Free) | Свободно/заето място на дисковете и точките на монтиране |
| **`du`** (Disk Usage) | Колко място заема папка/файл |
| **`mount`** | Закача файлова система към дървото на директориите |
| **`fsck`** (File System Check) | Проверява и поправя файловата система — **Linux аналог на chkdsk** |
| **`dd`** | Копиране **бит по бит**: **клониране** на диск, **образ** (.img/.iso — форензика), **изтриване** с нули. ⚠️ Прякори „Disk Destroyer“ — една грешна буква изтрива всичко |

## 7.6 👥 Потребители и права
- **`su user`** — превключване към друг потребител.
- **`sudo command`** — изпълнение на една команда с права на **root** (трябва да си в **sudoers**).
- `useradd`, `usermod`, `userdel`, `passwd` — създаване, промяна, изтриване, смяна на парола.
- `groupadd`, `groupmod`, `groupdel` — групи.

## 7.7 📦 Пакетни мениджъри
- **Package Manager (мениджър на пакети)** — автоматизира инсталиране, обновяване и премахване от **Repository (хранилище)** — цифрово подписани, проверени пакети.

| Дистрибуция | Формат | Мениджъри |
|---|---|---|
| **Debian-based** (Ubuntu) | **.deb** | **APT** (`apt`, `apt-get`) |
| **Red Hat-based** (RHEL, CentOS, Fedora) | **.rpm** | **RPM → YUM → DNF** (от най-стар към най-нов) |

- 🎯 `apt update` — **обновява списъка** с налични пакети; `apt upgrade` — **изтегля и инсталира** новите версии.
- 💡 За локален .deb файл използвайте `apt` (решава зависимостите).

## 7.8 📊 Процеси и мрежа

| Команда | Предназначение |
|---|---|
| **`top`** | **Динамичен Live** списък (като Task Manager); `k` — kill, `q` — изход |
| **`ps`** (`ps aux`, `ps -ef`) | **Статична снимка (Snapshot)**; комбинира се с `grep` (`ps -ef \| grep apache`) |
| **`ip`** | Мрежова информация и конфигурация (заменя стария **`ifconfig`**) |
| `ping -c 4 host` | В Linux ping не спира сам — `-c` задава брой |
| `traceroute` | Пътят до целта (Windows: `tracert`) |
| **`dig`** (Domain Information Groper) | По-мощният **nslookup** — A, AAAA, **MX**, TXT записи, TTL; `dig abv.bg MX`, `dig abv.bg +short` |
| **`curl`** (Client URL) | Пренос на данни към/от сървър (HTTP, HTTPS, FTP) — тест на уеб сървър или API |

## 7.9 🗜️ tar vs gzip
👉 **tar събира нещата в „торба“; gzip изстисква въздуха от нея.**

| Инструмент | Роля | Разширение |
|---|---|---|
| **TAR (Tape Archive)** | **Архивира** много файлове в един; пази структура, права и собственост; **не намалява размера** | .tar |
| **GZIP** | **Компресира** един файл | .gz |
| **Tarball** | Комбинацията | .tar.gz / .tgz |

- `tar -cvf archive.tar /folder` — създаване (**c**reate, **v**erbose, **f**ile).
- `tar -czvf archive.tar.gz /folder` — + **z** (gzip).
- `tar -xzvf archive.tar.gz` — разархивиране (e**x**tract).

## 7.10 💡 Добри практики и помощ
- **Обновления:** `apt-get` (Debian), `rpm`/`yum`/`dnf` (Red Hat).
- **Cron / Cron Jobs** — „будилникът“ на Linux; планирани задачи (напр. Backup). Еквивалент на **Task Scheduler**.
- **Samba** — Linux сървър предоставя файлове и принтери на Windows клиенти чрез **SMB**. 🎯 Смесена Windows/Linux среда → Samba.
- **Помощ:** `command --help`, `command --help | more` (страница по страница), **`man command`** (Manual Pages).
