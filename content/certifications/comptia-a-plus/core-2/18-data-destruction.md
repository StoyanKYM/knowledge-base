---
title: 18. 🗑️ Унищожаване на данни (Data Destruction)
updated: 2026-10-18
---

- **Data Remnants (остатъчни данни)** — частиците информация, останали след непълно изтриване.
- 👉 **Deleting (обикновено изтриване)** премахва само „адреса“ от File Table — данните се възстановяват за минути.

## 🔵 Електронно / логическо
| Метод | Описание |
|---|---|
| **Clearing** | Стандартен запис — защитава от обикновени програми, не от лаборатория |
| **Purging / Sanitizing** | Невъзможно възстановяване с известни форензични техники |
| **Overwriting / Wiping / Erasing** | Презаписване с нови данни (напр. **DBAN** — Drive Wipe) |
| **Zeroing / Zero Fill** | Всеки бит → 0 |
| **Standard Format** | Windows Format — по-добре от Wiping, но възстановимо |
| **Low-level Format** | Връща диска към фабрично състояние |
| **Secure Erase (ATA Secure Erase)** | Вградена команда в контролера на SSD/HDD |
| **Cryptographic Erase (CE)** | Унищожаване на **ключа за декриптиране** — данните стават „шум“ |

## 🔴 Физическо
| Метод | Описание |
|---|---|
| **Degaussing (демагнитизиране)** | Силно магнитно поле. ⚠️ **НЕ работи за SSD, CD, DVD** |
| **Drilling (пробиване)** | Дупки през плочите на HDD |
| **Shredding (раздробяване)** | 🎯 **Най-сигурното за SSD** |
| **Incinerating (изгаряне)** | Пещ |

💡 Retirement/Disposal на активи винаги включва Data Destruction.
