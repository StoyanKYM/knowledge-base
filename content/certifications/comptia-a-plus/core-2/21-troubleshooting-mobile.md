## 21.1 🔄 Нулиране и рестарт
- **Soft Reboot / Force Restart** — изчиства кеша и паметта (различно на всеки модел).
- **Android Safe Mode** — изключва приложенията от трети страни.
- **Factory Reset** — изтрива всички данни, приложения и настройки.

## 21.2 Чести проблеми

| Проблем | Причини / решения |
|---|---|
| **OS Update Failure** | Съвместимост, достатъчно батерия, добра мрежа (Wi-Fi вместо мобилни данни), натоварен сървър, недостатъчно място |
| **Random Reboots** | Прегряване, слаба батерия, дефектен хардуер, място, неуспешен ъпдейт, дефектно приложение |
| **Slow Performance** | Памет, **Processor Throttling**, слаба батерия |
| **App fails to launch** | Преинсталирайте |
| **App fails to close** | Force Quit / рестарт |
| **App crashes** | Проверете дали **MDM** не ограничава приложението |
| **Cellular** | Роуминг, избор на мрежа, Airplane Mode |
| **Wi-Fi** | Антената включена ли е; слабата батерия отслабва сигнала (Airplane Mode вече не спира Wi-Fi) |
| **Bluetooth** | Приближете устройствата; **Forget** и сдвоете отново |
| **NFC** | Минимално разстояние; Airplane Mode изключен |
| **Wireless File Transfer (AirDrop)** | Получателят в контактите; ограничете кой може да изпраща |
| **Battery Drain** | Известия, локация, фонови приложения, яркост, дълъг Screen Timeout, малуер, екстремни температури, край на живота на батерията; Airplane Mode пести |
| **Screen Autorotation** | **Rotation Lock**; приложение само в един режим; дефектен **акселерометър** |

## 21.3 🚩 Симптоми на мобилен малуер
- Много реклами; **фалшиви предупреждения за сигурност** / pop-ups;
- Бавна работа — батерията пада бързо, CPU се натоварва, мястото намалява без нови инсталации;
- **Limited Network Connectivity** — повреден DNS, **Redirection Attack**, инсталирано прокси;
- **Leaked Mobile Data** — данни изтичат към публичния интернет.
