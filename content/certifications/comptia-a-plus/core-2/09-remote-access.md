---
title: 9. 🌐 Отдалечен достъп (Remote Access)
updated: 2026-10-18
---

| Технология | Порт | Описание |
|---|---|---|
| **RDP – Remote Desktop Protocol** | **3389** | Microsoft; изпраща **графични команди**; целия десктоп или отделно приложение |
| **VNC – Virtual Network Computing** | **5900** | **Pixel-based (пикселен)** — „снимки“ на екрана; **Platform Independent (междуплатформен)**; ⚠️ базовият VNC **не е криптиран** (нужен SSH/VPN тунел); без звук и USB |
| **SPICE** | — | „Умен“ протокол за **виртуални машини** — изпраща графични команди, клиентът рендира (**QXL** драйвери); **звук, USB Passthrough, няколко монитора, споделен клипборд**; вградено **TLS** |
| **WinRM – Windows Remote Management** | **5985 (HTTP) / 5986 (HTTPS)** | Команден контрол „зад кулисите“ в мащаб чрез **PowerShell Remoting**; включен по подразбиране в Windows Server |
| **SSH – Secure Shell** | 22 | Криптиран команден ред |
| **Telnet** | 23 | ⚠️ Некриптиран |

👉 RDP — **виждаш** десктопа; WinRM — **командваш** зад кулисите. VNC праща **пиксели**; SPICE праща **команди**.
