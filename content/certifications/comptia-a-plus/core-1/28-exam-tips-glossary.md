## 28.1 💡 Съвети
- **Оставете симулациите (PBQ – Performance-Based Questions) за накрая.**
- При съмнение — **отговорете на всеки въпрос** (няма наказание за грешен отговор).
- Учебни източници: Dion Training (Udemy), Professor Messer (безплатен курс по 220-1201 в YouTube и professormesser.com).
- **Наизуст:** скорости на USB/SATA/Thunderbolt; категории кабели; 802.11 стандарти; портовете; RAID нивата; 7-те стъпки на лазерния печат; 6-те стъпки на Troubleshooting; капацитети на CD/DVD/BD; диапазоните на IP адресите.

## 28.2 📖 Речник на английски изрази

| Английски | Български |
|---|---|
| Performance Degradation | Влошаване на производителността (машината се забавя) |
| Plenum-rated | Огнеустойчив (за пленумни пространства) |
| Hot-swappable | С гореща замяна (без изключване) |
| Daisy Chain | Последователно (верижно) свързване |
| Backwards Compatible | Обратно съвместим |
| Legacy | Остарял / наследен |
| Proprietary | Собственост на конкретна компания (затворен стандарт) |
| Thermal Load | Топлинно натоварване |
| Throughput | Реална пропускателна способност |
| Bottleneck | Тясно място |
| Unsolicited | Непоискан / нежелан |
| Intermittent | Прекъсващ / периодичен |
| Tamper-proof | Защитен от намеса |
| Air-gapped | Физически изолиран от мрежи |
| Line of Sight | Пряка видимост |
| Baseline | Базово (нормално) ниво |
| Workaround | Заобиколно решение |
| Escalate | Ескалирам (предавам на по-високо ниво) |
| Remediate | Отстранявам / коригирам |
| Intact | Непокътнат |
| Telemetry | Телеметрия — автоматично събиране и предаване на данни от отдалечени източници |
