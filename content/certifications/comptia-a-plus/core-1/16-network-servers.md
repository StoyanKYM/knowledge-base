## 16.1 🗄️ Сървъри и услуги

| Сървър / услуга | Описание |
|---|---|
| **File Server (файлов сървър)** | Централизирано съхранение на файлове. Windows: **SMB (445)**, стари — **NetBIOS (137–139)**; Linux: **Samba** (SMB за Windows клиенти); Apple: AFP – Apple Filing Protocol |
| **Print Server (сървър за печат)** | Централизирано управление на печата и драйверите (инсталират се веднъж) |
| **Web Server (уеб сървър)** | HTTP (80) / HTTPS (443). Софтуер: **IIS – Internet Information Services** (Windows), **Apache** (Linux), **NGINX** (бърз; Reverse Proxy, Load Balancer, кеш). Static (статични) и Dynamic (динамични) страници |
| **Mail Server (пощенски сървър)** | SMTP, POP3, IMAP; **Microsoft Exchange** в корпоративна среда |
| **AAA Server** | Authentication, Authorization, Accounting (вижте 16.2) |
| **Database Server (сървър за бази данни)** | Store (съхранение), Process (обработка на заявки), Secure (защита) |
| **NTP Server** | Синхронизация на времето |
| **Syslog Server** | Централизирано събиране на логове |
| **Proxy Server (прокси сървър)** | Посредник между клиента и интернет |
| **Load Balancer / Content Switch (балансьор на натоварването)** | Разпределя заявките между сървъри |
| **Spam Gateway (спам шлюз)** | Спира нежеланата поща, преди да достигне до потребителя |
| **UTM / Next-Generation Firewall** | „Швейцарско ножче“ на сигурността |

## 16.2 🛂 AAA – Authentication, Authorization, Accounting (автентикация, оторизация, отчетност)
- **Authentication (автентикация)** — кой сте; **Authorization (оторизация)** — какво може да правите; **Accounting (отчетност)** — проследяване и логване на дейността.
- **Digital Certificates (цифрови сертификати)** — потвърждават самоличността (и сървър към сървър).

| Протокол | Транспорт | Порт | Типична употреба |
|---|---|---|---|
| **RADIUS – Remote Authentication Dial-In User Service** | **UDP** | 1812/1813 | Достъп на крайни потребители до **Wi-Fi (802.1X) и VPN** |
| **TACACS+ – Terminal Access Controller Access-Control System Plus** | **TCP** (по-надежден) | 49 | Администратори, управляващи мрежово оборудване (Cisco) |

## 16.3 🗃️ Database Servers (сървъри за бази данни)
| Тип | Описание |
|---|---|
| Relational / SQL (релационни) | Таблици и редове; инвентар |
| NoSQL | Неструктурирани/полуструктурирани данни; анализи в реално време, социални мрежи |
| In-memory (в паметта) | Данните са в RAM за ултра бърза работа; кеширане |

## 16.4 ⏰ NTP – Network Time Protocol (протокол за мрежово време)
- Гарантира точно и синхронизирано време — критично за подреждане на събития, Troubleshooting и сигурност.
- **Йерархия Stratum (стратум):** Stratum 0 — референтен часовник (атомен/GPS) → по-ниските нива → крайните устройства.
- 🎯 В **Active Directory**, ако часовникът на лаптопа се различава с **повече от 5 минути** от сървъра, **автентикацията (Kerberos) се проваля**.
- Без защита NTP може да се злоупотреби за DDoS атаки.

## 16.5 📜 Syslog
- Протокол и сървър за изпращане на логове от устройства и приложения към **централизирано място** — „черната кутия“ на мрежата.
- Съобщението съдържа: **Priority Code (код на приоритета)** = **Facility (източник)** + **Severity (критичност, 0–7: от Emergency до Debug)**; **Header (заглавие)**; **Message Body (тяло)**.
- Предимства: централно хранилище, автоматизирани известия, **Compliance (регулаторно съответствие)** — здравеопазване, финанси.

## 16.6 🕵️ Proxy Server (прокси сървър)
- Клиентът изпраща заявка към проксито → проксито я изпълнява → връща резултата (ако е легитимен и безопасен).
- Употреба: сигурност, контрол на достъпа, **Caching (кеширане — спестява Bandwidth)**, URL филтриране, сканиране на съдържание.
- **Forward Proxy (препращащ прокси)** — в мрежата, контролира къде ходят служителите.
- **Reverse Proxy (обратен прокси)** — пред сървърите, защитава ги отвън.

## 16.7 ⚖️ Load Balancer (балансьор на натоварването)
- „Регулировчик“ пред сървърите — разпределя заявките; при отказ на сървър го изважда от ротацията автоматично → Uptime и Availability.
- 🎯 Web Content Filtering се прави на **рутер/UTM**, не на суич; балансиране на трафика — на **Load Balancer**.
- Защита от **DDoS – Distributed Denial of Service (разпределена атака за отказ на услуга)**: **Blackholing/Sinkholing**, **IPS – Intrusion Prevention System (система за предотвратяване на прониквания)**, еластична облачна инфраструктура (скъпа).

## 16.8 🧱 UTM и Firewalls
- **UTM** интегрира: Firewall, URL Filtering, Content Inspection, Malware Inspection, Spam Filter, IPS. Известно и като **Web Security Gateway**.
- Типове Firewall: **Packet-filtering (филтриране на пакети)**, **Stateful (със състояние)**, **Stateless (без състояние)**.
- **ACL – Access Control List** — правила за разрешаване/блокиране на трафик.
- **Screened Subnet (екранирана подмрежа)** — бившата **DMZ – Demilitarized Zone (демилитаризирана зона)**.

## 16.9 🏭 ICS / SCADA, Embedded и Legacy системи
- **OT – Operational Technology (операционни технологии)** — технологии, взаимодействащи с физическия свят (за разлика от IT); често в **Air-gapped (физически изолирани)** мрежи.
- **ICS – Industrial Control System (индустриална система за управление)** — автоматизация на процеси чрез вградени устройства. Няколко ICS = **DCS – Distributed Control System (разпределена система за управление)**.
- **SCADA – Supervisory Control and Data Acquisition (надзорен контрол и събиране на данни)** — ICS за **мащабни, многообектни** съоръжения в географски регион (енергетика, рафинерии, производство, логистика), управлявани от централен компютър. Изисква **напълно сегментирана мрежа**.
- **PLC – Programmable Logic Controller (програмируем логически контролер)** — индустриален компютър (сглобяеми линии, роботика, отваряне/затваряне на клапани); работи на фърмуер, рядко се кърпи.
- **Fieldbus** — сериен протокол, свързващ PLC-тата.
- **HMI – Human-Machine Interface (интерфейс човек–машина)**.
- **Embedded System (вградена система)** — специализиран компютър с една мисия (спирачки на кола, микровълнова, алармени системи, контрол на врати, системи за отчитане на работно време); обикновено без директен достъп до ОС. Използва **RTOS – Real-Time Operating System (ОС за реално време)**.
- **Legacy System (наследена система)** — вече не се поддържа от производителя и не получава кръпки за сигурност.
