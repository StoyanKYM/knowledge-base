| Симптом / сценарий | Отговор |
|---|---|
| Компютърът „забравя“ датата/часа | Смяна на **CMOS батерията (CR2032)** |
| 1 кратък звуков сигнал при стартиране | Нормален POST |
| Внезапни изключвания/рестарти | Прегряване — проверете охлаждането |
| Подути кондензатори на дънната платка | Повредена дънна платка |
| Щракане/стържене от HDD | Механичен отказ — незабавен Backup |
| S.M.A.R.T. грешка | Незабавен Backup |
| Дефрагментиране на SSD | **Никога** |
| „No Boot Device Found“ | Boot Order, кабели, MBR/GPT |
| Зареждане на ОС от мрежата | **PXE** |
| Зареждане само на подписана ОС | **Secure Boot (UEFI)** |
| Ключът на BitLocker | **TPM** |
| Централизирано управление на хиляди ключове | **HSM** |
| Сървърна памет, която поправя грешки | **ECC** |
| > 4 GB RAM | 64-битова ОС |
| Лаптоп RAM | **SODIMM** |
| Видеокарта | **PCIe x16** |
| Най-бърз SSD интерфейс | **M.2 NVMe** (PCIe) |
| Само скорост, без защита | **RAID 0** |
| Огледално копие, 2 диска | **RAID 1** |
| Минимум 3 диска с четност | **RAID 5** |
| Издържа отказ на 2 диска | **RAID 6** |
| Скорост + защита, 4 диска | **RAID 10** |
| Свързване на няколко монитора последователно | **DisplayPort** (или Thunderbolt) |
| Нов лаптоп към стар VGA проектор | Digital-to-Analog Converter |
| Защита на съдържанието по HDMI | **HDCP** |
| Аналогово видео само | **VGA**, DVI-A |
| PC → Switch | **Straight-through** кабел |
| PC → PC / Switch → Switch | **Crossover** (T568A ↔ T568B) |
| Кабел над окачен таван (въздуховод) | **Plenum-rated (CMP)** |
| 10 Gbps на 100 m | **Cat 6a** |
| 40 Gbps, 30 m, Data Center | **Cat 8** |
| Минимален кабел за 1 Gbps | **Cat 5e** |
| Дълги разстояния по оптика | **Single-mode (жълт)** |
| Имунитет срещу EMI | **Fiber Optic** |
| Кабелна ТВ / интернет кабел | **RG-6**, F-type |
| CCTV камери (аналогови) | **RG-59** |
| Телефонна линия / DSL | **RJ-11** |
| Конзола на стар рутер/суич | **DB-9 / RS-232** (Serial / Rollover) |
| Намиране на кабел в стената | **Toner Probe** |
| Копие на трафика без In-line | **Network Tap** |
| Терминиране в Patch Panel | **Punchdown Tool** |
| Захранване на камера в тавана | **PoE** |
| IP адрес 169.254.x.x | **APIPA** — няма връзка с DHCP |
| `ping 127.0.0.1` успешен | TCP/IP стекът работи |
| fe80:: адрес | Нормален IPv6 Link-local |
| Един публичен IP за много устройства | **NAT** |
| Винаги същия IP за принтер | **DHCP Reservation** (по MAC) |
| Име → IPv4 / IPv6 | **A / AAAA** запис |
| Пощенски сървър на домейна | **MX** запис |
| Псевдоним на домейн | **CNAME** |
| Оторизирани изпращачи на поща | **SPF** |
| Криптографски подпис на пощата | **DKIM** |
| Политика при неуспешна SPF/DKIM | **DMARC** |
| Логическо разделяне на мрежата на един суич | **VLAN** (Trunk — 802.1Q) |
| Две офиса, криптирано през интернет | **Site-to-Site VPN** |
| VPN през браузъра | **Clientless VPN** |
| Wi-Fi/VPN автентикация на потребители | **RADIUS (UDP)** |
| Администриране на мрежово оборудване | **TACACS+ (TCP)** |
| Логване от всички устройства на едно място | **Syslog** |
| Неуспешен вход в AD заради часовника | **NTP** (разлика > 5 мин) |
| Всичко в едно: Firewall + AV + спам + URL филтър | **UTM** |
| Индустриални обекти в географски регион | **SCADA** |
| Най-добра домашна Wi-Fi защита | **WPA2/WPA3 с AES** |
| Корпоративна Wi-Fi автентикация | **WPA2/WPA3-Enterprise (802.1X)** |
| Защита от офлайн Brute-force | **WPA3 SAE** |
| Двулентови Wi-Fi стандарти | **802.11n и 802.11ax** |
| Wi-Fi 6E | Добавя **6 GHz** |
| Смущения от микровълнова фурна | **2.4 GHz** |
| Непоискани Bluetooth съобщения | **Bluejacking** |
| Кражба на данни по Bluetooth | **Bluesnarfing** |
| Безконтактно плащане | **NFC** |
| Проследяване на инвентар | **RFID** |
| Домашна автоматизация, 900 MHz | **Z-Wave** (Zigbee — 2.4 GHz) |
| Голяма латентност на интернета | **Satellite (GEO)** |
| Селски район, антена с пряка видимост | **WISP** |
| Кабелен интернет стандарт | **DOCSIS** |
| Оптика директно в дома | **FTTP/FTTH** + ONT |
| Лаптоп ↔ периферия с допълнителни карти | **Docking Station** |
| Само дублиране на портове | **Port Replicator** |
| Докосването не реагира, образът е наред | **Digitizer** |
| Много тъмен лаптоп екран (стар CCFL) | **Inverter** или Backlight |
| Подута батерия | Не отваряйте — извадете от употреба |
| Потребителско име + парола + PIN | Все още **еднофакторна** автентикация |
| Корпоративни данни на личен телефон | **MAM** (BYOD) |
| Управление на фирмени устройства | **MDM** |
| Бягство от VM към хипервайзора | **VM Escape** |
| Неконтролирано разрастване на VM | **VM Sprawl** |
| Хипервайзор директно върху хардуера | **Type 1** (Hyper-V, ESXi) |
| Хипервайзор върху Windows/macOS | **Type 2** (VirtualBox) |
| Споделено ядро на ОС | **Containers** |
| Изпълнение на конзолна игра на PC | **Emulation** |
| Безопасен анализ на зловреден софтуер | **Sandbox** |
| Десктоп като абонамент | **DaaS / VDI** |
| Изходящ облачен трафик | **Egress** — таксува се |
| Лазерен принтер — размазан тонер | **Fuser** |
| Не поема хартия | **Pickup Rollers** |
| Поема няколко листа | **Separation Pad** |
| Засядане само при двустранен печат | **Duplex Assembly** |
| Изцяло черни страници | **Primary Charge Roller** / високо напрежение |
| Бели ивици / ехо образи | **Барабанът** |
| Нечетливи символи | **Драйвер** |
| Опашката е блокирана | Рестарт на **Print Spooler** |
| Липсващи линии/цветове (Inkjet) | **Cleaning Cycle** на главите |
