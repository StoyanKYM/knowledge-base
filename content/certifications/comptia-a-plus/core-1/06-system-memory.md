## 6.1 🪜 Йерархия на паметта

| Ниво | Скорост | Устойчивост |
|---|---|---|
| Cache (кеш) — в процесора | Изключително бърз | Volatile (енергозависим) |
| RAM / System Memory (оперативна памет) | Наносекунди | Volatile — губи се при изключване |
| Virtual Memory (виртуална памет) — Page File (Windows) / Swap Space (Linux/macOS) | Много по-бавна (на диска) | Временна |
| Mass Storage (масово съхранение) — HDD/SSD | Милисекунди (HDD) | Non-volatile / Persistent (енергонезависим / постоянен) |

- **RAM – Random Access Memory (памет с произволен достъп)** — бързо временно хранилище за заредените приложения и файлове. 🎯 **RAM не е устройство за съхранение.** Компютърът работи само с данни, заредени в RAM.
- Добавянето на RAM е **един от най-лесните начини** за ускоряване на компютъра.
- **Virtual Memory (виртуална памет)** — място на диска, което ОС заделя и което „се преструва“ на RAM, когато физическата памет не стига.

## 6.2 📍 Addressing Memory (адресиране на паметта)
- Всяка клетка в RAM има уникален адрес. Между CPU и паметта стои **Memory Controller (контролер на паметта)** — „регулировчик“, свързан чрез шина.
- **Data Bus (шина за данни)** — колко данни на такт (Single Channel = 64 бита).
- **Address Bus (адресна шина)** — колко адреса CPU може да следи (32 бита ≈ 4 GB; 64 бита ≈ 16 EB).

## 6.3 🧱 Memory Modules (модули памет)
- **DIMM – Dual In-line Memory Module (двуредов модул памет)** — контактите от двете страни са независими (64-битов път). Предшественик: SIMM – Single In-line.
- **SODIMM – Small Outline DIMM (DIMM с малък профил)** — около половината от размера, за **лаптопи**; поставя се под **45°** и се натиска надолу (настолните — отгоре, вертикално).
- **DRAM – Dynamic RAM (динамична RAM)** — клетките трябва да се презареждат на всеки няколко милисекунди.
- **SDRAM – Synchronous DRAM (синхронна DRAM)** — синхронизирана с общия часовник на системата.
- **DDR – Double Data Rate (двойна скорост на данни)** — пренася данни **два пъти на такт**.

| Тип | Пинове (DIMM / SODIMM) | Пропускателна способност | Максимален модул |
|---|---|---|---|
| DDR3 | 240 / 204 | 6.4–17 GB/s | 8 GB |
| DDR4 | 288 / 260 | 12.8–25.6 GB/s | 32 GB |
| DDR5 | 288 / 262 | 38.4–51.2 GB/s | 128 GB |

🎯 Правила при покупка:
- **Keying (ключ/прорез):** DDR3, DDR4 и DDR5 **не са съвместими** — прорезите са на различни места.
- Модули с различна скорост от един тип могат да се смесват, но **всички работят със скоростта на най-бавния**.
- Купувайте модули **по двойки** — същата марка, скорост и пропускателна способност.
- **Single Bank (единична банка)** — всякакъв размер във всеки слот; **Paired Banks (сдвоени банки)** — модулите се поставят по двойки.

## 6.4 🛣️ Multi-channel Memory (многоканална памет)

| Режим | Минимум модули | Ширина на шината | Типична употреба |
|---|---|---|---|
| Single Channel (едноканален) | 1 | 64-bit | Бюджетни офис компютри |
| Dual Channel (двуканален) | 2 | 128-bit | Гейминг / стандартен офис |
| Triple Channel (триканален) | 3 | 192-bit | Стари ентусиастки платформи |
| Quad Channel (четириканален) | 4 | 256-bit | Сървъри / видеообработка |

- Използвайте **идентични модули** в правилните слотове (обикновено в един цвят); проверете ръководството на дънната платка.

## 6.5 ✅ Видове памет според проверката за грешки

| Тип | Открива грешки? | Поправя грешки? | Употреба |
|---|---|---|---|
| Non-parity / Standard (без паритет / стандартна) | ❌ | ❌ | Домашни компютри; евтина. Грешка → срив / BSOD |
| Parity (с паритет) | ✅ (1 бит) | ❌ | По-стари системи |
| **ECC – Error Correcting Code (код за коригиране на грешки)** | ✅ | ✅ (1 бит в реално време; открива 2 бита и спира системата) | **Сървъри** и високопроизводителни работни станции; по-бавна и по-скъпа |

- **Parity Bit (бит за четност):** към 8 бита данни се добавя 9-и бит, така че броят единици да е четен (Even) или нечетен (Odd). Ако правилото е нарушено — има грешка. Не може да я поправи; при две грешки може да не я открие.
- ECC модулите често имат **9 чипа вместо 8**. Иначе модулите изглеждат еднакво — проверявайте спецификацията.
- **Buffered / Registered Memory (буферирана / регистрова памет)** — допълнителен Register (регистър) между паметта и CPU за надеждност; използва се в сървъри.
