## 26.1 🔗 Connectivity / Queue Issues (свързаност и опашка)
- **Online/Offline (онлайн/офлайн)** — **вътрешният статус** на принтера, не мрежовата връзка. В Offline режим отказва задачи (няма хартия, грешка при подаване, повредена задача).
- **Stuck Print Job (заседнала задача)** блокира цялата опашка. Решения:
  1. Изчистете опашката ръчно;
  2. 🎯 **Restart the Print Spooler (рестартирайте спулера)**;
  3. Обновете драйверите.
- **Power Cycling (изключване и включване)** на принтера.
- **Windows Printer Test Page (тестова страница от Windows)** — информация за драйвери, мастило, надраскан барабан, ехо образи.
- 🎯 Много задачи висят в опашката → **Print Spooler**.

## 26.2 📄 Feed Issues (подаване на хартия)

| Проблем | Причина |
|---|---|
| **Paper Jam (засядане)** | Лист заседнал по пътя; при засядане само при двустранен печат → Duplex |
| **Paper Not Feeding (не поема хартия)** | 🎯 **Износени Pickup Rollers** — станали гладки |
| **Multipage Misfeed (поема няколко листа)** | Pickup Rollers / **Separation Pad** |
| **Grinding Noises (стържещи шумове)** | Зъбни колела или валяци |
| **Tray Not Recognized (тавата не се разпознава)** | Тавата не е поставена правилно или сензорите не работят |

## 26.3 🎨 Print Quality Issues (качество на печата)

| Симптом | Причина / решение |
|---|---|
| **Faded Prints (избледнели)** | Малко мастило/тонер или **Draft Mode** → сменете касетата |
| **Blank Pages (празни страници)** | Софтуер/драйвер изпраща празна страница; **неотстранена защитна лента** на тонера/мастилото; празна касета |
| **White Stripes (бели ивици)** | **Мръсен барабан** — пречи на тонера да полепне (лазерни) |
| **Black Pages / Stripes (изцяло черни страници)** | **Замърсен/повреден Primary Charge Roller** или неизправно високо напрежение |
| **Speckling (петна)** | **Разпилян тонер** вътре в принтера |
| **Vertical/Horizontal Lines (линии)** | Мръсни подаващи валяци или **повреден фоточувствителен барабан**; при inkjet — запушени дюзи |
| **Toner Not Fused / Smudging (размазване)** | 🎯 **Fuser** — тонерът не е достатъчно нагрят |
| **Double/Echo/Ghost Images (ехо образи)** | Барабанът не изчиства остатъчния тонер между задачите |
| **Incorrect Chroma (грешни цветове)** | Тонер касетите са поставени на **грешни места**; калибриране |
| **Color Missing (липсващ цвят)** | Празна или запушена касета |
| **Garbled Prints (нечетливи символи)** | 🎯 **Драйвер или шрифтове** — данните се повреждат при предаването |
| **Missing Dots (липсващи точки — Dot-Matrix)** | Износени **игли на печатащата глава** |
| **Stalled/Delayed Print (забавен печат)** | Опашката или спулерът |

## 26.4 📎 Finishing Issues (довършителни операции)
- **Incorrect Page Size (грешен размер)** — **US Letter (8½ × 11")** срещу **A4** (малко по-голям); съпоставете размера в документа и в тавата.
- **Incorrect Orientation (грешна ориентация)** — Portrait (документи) / Landscape (таблици, презентации).
- **Stapling Jams (засядане на телбода)** и проблеми с **Hole Punching (пробиване на дупки)**.
- **Tray Not Recognized** — тавата не е поставена правилно / неизправни сензори.
