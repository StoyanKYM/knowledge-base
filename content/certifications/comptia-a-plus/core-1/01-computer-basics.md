## 1.1 🖥️ Какво е компютър

Всяко устройство, което изпълнява следните **4 основни функции**, по дефиниция е компютър:

| Функция | Описание | Примери |
|---|---|---|
| Input (вход) | Приемане на данни във форма, която компютърът може да използва | Клавиатура, мишка, микрофон |
| Processing (обработка) | Процесорът получава информацията и действа върху нея | CPU, GPU |
| Output (изход) | Показване на обработените данни във форма, полезна за потребителя | Монитор, принтер, говорители |
| Storage (съхранение) | Запазване на данни временно или постоянно | RAM, SSD, HDD |

**Типове компютри:**
- Workstation / Desktop PC (работна станция / настолен компютър) — корпус тип „кула“, който стои на бюрото.
- Server (сървър) — предоставя ресурсите си (файлове, уебсайт) на други компютри. Управлява се обикновено отдалечено през Command Line Interface – CLI (интерфейс от команден ред).
- Laptop (лаптоп) — мобилна версия на работната станция.
- Tablet (таблет) — преносим компютър със сензорен екран.
- Smartphone (смартфон) — по-малък таблет, който може да провежда разговори.
- Smart Devices (интелигентни устройства) — изчисляват без клавиатура и мишка (Google Home, Alexa).
- Internet of Things – IoT Devices (устройства за интернет на нещата) — устройства, свързани към мрежа.

**Hardware, Software, Firmware:**
- Hardware (хардуер) — физическите части на компютъра.
- Software (софтуер) — инструкции за хардуера:
  - OS Software (операционна система) — съхраняване, извличане, промяна, печат и предаване на информация;
  - Application Software (приложен софтуер) — създаване, съхранение, промяна и преглед на данни;
  - Drivers (драйвери) — превеждат командите на ОС към конкретен хардуер.
- Firmware (фърмуер) — „софтуер върху чип“, вграден в хардуера (дънна платка, видеокарта, мрежова карта). Обновява се чрез процес, наречен **Flashing (флашване)**.

## 1.2 📏 Единици за данни

| Единица | Стойност |
|---|---|
| Bit – b (бит) | Най-малката единица: 0 или 1 |
| Nibble (полубайт) | 4 бита |
| Byte – B (байт) | 8 бита — място за един символ |
| Kilobyte – KB (килобайт) | 1024 байта (≈ ⅓ страница текст) |
| Megabyte – MB (мегабайт) | 1024 KB (≈ книга, минута музика, снимка) |
| Gigabyte – GB (гигабайт) | 1024 MB |
| Terabyte – TB (терабайт) | 1024 GB |

🎯 **Data Transfer (пренос на данни) се измерва в битове в секунда (bps); Data Storage (съхранение) — в байтове.**
- Пример: 50 бита за 2 секунди = 25 bps. 1 Kbps = 1000 бита в секунда.
- Преобразуване: 1000 b / 8 = 125 B.
- Малко **b** = бит, голямо **B** = байт.

## 1.3 ⚡ Electrostatic Discharge – ESD (електростатичен разряд)
- Внезапно претичане на статично електричество между два обекта с различен електрически потенциал (например от тялото ви към компонент). Един от „тихите убийци“ на хардуера.
- Може да повреди Chips (чипове), Resistors (резистори) и Capacitors (кондензатори).
- Предпазни мерки: антистатична гривна, антистатична подложка, антистатични пликове, заземяване.
